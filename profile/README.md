# Sistema de Gerenciamento de Estoque

Laboratório prático de arquitetura de software utilizando Java,
Spring Boot e Apache Kafka.

O projeto explora progressivamente problemas reais de sistemas
distribuídos, como:

- concorrência;
- processamento assíncrono;
- máquinas de estado;
- idempotência;
- consistência distribuída;
- observabilidade;
- infraestrutura e AWS.

A arquitetura evolui conforme os problemas aparecem:
nenhuma tecnologia é adicionada sem uma necessidade concreta.
